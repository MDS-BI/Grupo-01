# Destination Manager (Vite + Vanilla JS)

Minimal single-page app for managing tourist destinations using Vite and browser localStorage.

## Setup

Install dependencies and run the dev server:

```bash
npm install
npm run dev
```

Open http://localhost:5173 (or the URL Vite prints).

## Tests

Run the unit tests with:

```bash
npm test
```

## Notes

- Data is persisted to `localStorage` under the key `destination_manager:destinations`.
- This project intentionally uses vanilla HTML, CSS, and JavaScript for simplicity.
