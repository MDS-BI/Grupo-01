# Quickstart: Tourist Destination Manager

## Setup

1. Install dependencies with `npm install`.
2. Start the development server with `npm run dev`.
3. Open the local Vite URL in a browser.

## Core User Flow

1. Create a destination using the form.
2. Search for a destination using the search box.
3. Edit or delete a destination from the list.
4. Refresh the page to confirm that destinations persist in local storage.

## Validation

- Verify that required fields show validation errors.
- Verify that search results update as the user types.
- Verify that the list stays consistent after edit and delete actions.
